# Crime-Network-Investigation
Notebook created to calculate network centrality statistics and visualize how they change with time over the course of an investigation into a drug trafficking network.
This study uses the CAVIAR set of time-varying graphs spanning 11 phases of investigation on a criminal network between 1994 and 1996 (https://www.kaggle.com/datasets/chiragtagadiya/caviar/data); the cell of code used to import the data is given by this source.
